## Scope & Scientific Boundary

This repository hosts open-access materials for a 30-day observational protocol examining how structured nightly cognitive conditioning, self-hypnosis, and contemplative prayer scripts relate to autonomic nervous system regulation and epigenetic resilience.

* **Epigenetic Focus (Non-Sequence):** Focused on epigenetic regulation—gene expression and physiological stress/recovery dynamics—rather than altering underlying DNA sequences.
* **Intended Purpose:** Exploring non-invasive cognitive conditioning and stress resilience to support healthier lives for practitioners and future generations.
* **Current Stage:** Open-access preprint published with an active community review request on PREreview for public feedback and methodological discussion.
